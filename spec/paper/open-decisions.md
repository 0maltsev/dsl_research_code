# Research contract and open decisions

## Research contract

**Scope.** The object of study is a stateless financial contract represented by a total, pure function over scalars and explicitly bounded immutable arrays. The DSL has fixed-width integer and binary64 floating-point primitives, conditionals, bindings, a capacity-indexed numeric fold, an immutable bounded builder, and calls through an acyclic declaration order. It excludes persistence, networking, consensus, dynamic dispatch, recursion, unbounded iteration, general heap growth, and ambient host effects.

**Central question.** Can this restriction, exact/upper/capacity size summaries, and a compositional resource/footprint semantics support sound static upper bounds for source events and peak-live scratch; can a scalar DSL--BIR--Wasm translation preserve observable outcomes under explicit memory assumptions; and what performance cost does this boundary impose relative to semantically constrained native C++?

**Research questions.** RQ1 and RQ2 combine formal target status with separate counterexample-finding artifact gates. RQ3 estimates per-family AOT-Wasm/native ratios for matched scalar and production-optimised builds. RQ4 estimates workload-size interaction within each kernel. RQ5 measures explicit SIMD for K1 and K2 only as a non-pooled ablation. K3 remains MS/PO; call-boundary decomposition is diagnostic, not a replacement estimand.

**Hypothesis decisions.** G1 and G2 pass only as artifact gates when no counterexample is detected at the declared coverage; they never prove soundness or preservation. Performance decisions are made per kernel/size/build family from simultaneous intervals relative to a frozen equivalence band. Size effects are within-kernel. SIMD decisions use within-form speedups and their interaction. Unsupported, contradictory, or underpowered cases are reported unresolved rather than forced into a direction.

**Contributions claimed now.** The manuscript defines a self-contained source calculus, finite count-certificate fragment, functional canonical-NaN primitive table, rooted immutable-store semantics, finite scalar candidate event/footprint analysis, mathematical BIR machine, checked liveness/slot-colouring specification with a no-reuse fallback, source--BIR and BIR--Wasm constructors, aligned frame/output/linear-memory accounting, and a preregisterable three-matrix experiment. It proves source termination, source determinism modulo rooted fresh-name equivalence, certificate soundness, and finite capacity instantiation. Type/size preservation, static resource soundness, simulations, target-fault exclusion, end-to-end preservation, and K1/K2 SIMD equivalence remain proof obligations. It claims no implementation, mechanisation, measurement, or empirical direction.

**Assumptions.** ABI inputs pass capacity and layout validation; `f\prec_M g` enforces acyclic calls; accepted counts carry checked finite derivations; floating primitive NaNs canonicalise to one source word; evaluation is strict left-to-right; imports are absent; target regions for simultaneously live source objects are disjoint; scratch reuse requires a checked colouring/death certificate or uses no reuse; Wasm32 endpoints are checked below \(2^{32}\); and the validator/runtime conform to the frozen target subset.

**Non-goals.** Cycle-accurate WCET, machine-latency guarantees from source counts, distributed state, blockchain protocol design, concurrency, general mutable arrays, automatic financial model selection, dynamic memory management, and general-purpose programming are outside scope.
